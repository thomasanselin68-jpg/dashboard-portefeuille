# Dashboard Portefeuille - Test Technique Natixis Wealth Management

Ce projet a été réalisé dans le cadre du processus de recrutement pour l'équipe Produits Structurés. 
    
Il s'agit d'un tableau de bord interactif développé avec HTML, CSS et JavaScript, permettant de visualiser un portefeuille fictif à partir d'un fichier CSV.

Fonctionnalités :
- Calcul et affichage des métriques globales (nombre de lignes, nominal total, valorisation totale).
- Tableau interactif des positions avec un filtre de recherche par nom de client.
- Détection et mise en évidence des données manquantes (émetteur ou valorisation absents).
- Alerte sur les produits "sous surveillance" (lorsque le niveau actuel du sous-jacent est à 5% ou moins de la barrière de protection du capital).
